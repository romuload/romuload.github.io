How I work

  1. I start with the data. Before I design anything, I look for what already shows where the journey gets stuck and where customers give up.
  2. I align with the trio. With product and engineering, I build a CSD matrix (certainties, assumptions and doubts), so we all agree on the problem we’re solving. Then we raise solution hypotheses.
  3. I set a plan with a deadline. I define what we’ll do in that period and what we’ll test along the way.
  4. I test and iterate. Each round of usability and user testing shows where the product should go next, whether that means easier to use or more conversion.
